# Mobil Yazılım Kulübü Web Sitesi

Bu proje, mobil yazılım ekosistemine odaklanan ve üniversite bünyesinde faaliyet gösteren bir öğrenci topluluğunun resmi web sitesi taslağıdır. Proje tamamen yerel olarak tarayıcıda çalıştırılabilecek şekilde saf (Vanilla) HTML, CSS ve JavaScript kullanılarak premium bir tasarımla geliştirilmiştir.

## 🚀 Özellikler

- **Premium Tasarım & Canlı Estetik**: Koyu tema odaklı, neon mor ve neon camgöbeği gradyanlı, cam efekti (glassmorphism) kullanan modern kullanıcı arayüzü.
- **Tam Duyarlı (Responsive)**: Mobil, tablet ve masaüstü cihazlar için tamamen optimize edilmiş düzen ve menü sistemi.
- **Yapay Zeka Destekli Mobil App Fikir Oluşturucu**: Kullanıcıların kategori ve zorluk derecesi seçerek anında mobil uygulama fikirleri ve teknoloji yığınları (Swift, Kotlin, Flutter vb.) türetebildiği dinamik modül.
- **Yumuşak Sayfa Geçişleri & Animasyonlar**: Performansı olumsuz etkilemeyen, CSS tabanlı yumuşak kaydırma ve yüklenme animasyonları.
- **İnteraktif İstatistik Sayacı**: Hero bölümünde kulübün başarı rakamlarını ekran görünür olduğunda animasyonlu olarak artıran mekanizma.
- **Dinamik Üyelik Başvuru Formu**: Form doğrulaması ve yükleme animasyonlarıyla zenginleştirilmiş kayıt alanı.

## 📁 Proje Dosya Yapısı

- `index.html` - Ana sayfa iskeleti, tüm bölümler ve SEO meta etiketleri.
- `css/style.css` - Tasarım sistemi değişkenleri, yerleşim kodları ve animasyonlar.
- `js/app.js` - Sayfa etkileşimleri, sayaçlar, mobil menü ve fikir oluşturucu algoritması.

## 💻 Yerel Çalıştırma

Proje herhangi bir derleme aracı veya harici paket yöneticisi (npm) gerektirmez. Aşağıdaki yöntemlerden biriyle çalıştırabilirsiniz:

1. **Doğrudan Tarayıcıda Açma**: `index.html` dosyasına çift tıklayarak tarayıcınızda açabilirsiniz.
2. **VS Code Live Server (Tavsiye Edilen)**: VS Code kullanıyorsanız `Live Server` eklentisi yardımıyla projeyi `http://127.0.0.1:5500` adresinde yerel sunucu olarak çalıştırabilirsiniz.
